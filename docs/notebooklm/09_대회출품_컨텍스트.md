# 2026 AX 아이디어 경진대회 출품 컨텍스트

## 대회 정보
- **대회명**: 2026년도 AX 아이디어 경진대회 (데이터 활용_제품·서비스 개발 사업 부문)
- **선택 미션**: (2) 에너지산업, 에너지효율, 미래에너지, 에너지환경

## 출품 정보
- **팀명**: 페트로피디아
- **제품·서비스명**: OilLens (글로벌 원유 가격 인텔리전스 플랫폼)
- **수상 이력**: 해당 없음 (에코톤/K-water 수상 이력 없음)

## 핵심 아이디어 요약
한국석유공사 오피넷 공공데이터와 글로벌 에너지·경제 공공 데이터(EIA, FRED)를 결합하고, RAG(Retrieval-Augmented Generation) 기반 LLM과 XGBoost ML 모델의 하이브리드 추정 엔진으로 국제 유가(Dubai/Brent/WTI)의 단기 전망과 변동 원인 분석을 자동화하는 AI 인텔리전스 대시보드.

## 주요 타겟 고객
- 에너지/석유화학/제조업 B2B 실무자 (원자재 구매·기획팀)
- 에너지 시장 분석가 및 리서치 기관
- 정유사·트레이딩 하우스의 리스크 관리 부서
- 에너지 분야 정책 입안자 및 연구기관

## 활용 데이터 목록

### 공공 데이터
1. **한국석유공사 오피넷 유가정보** — Dubai/Brent/WTI 일별 현물가(USD). 공공데이터포털(data.go.kr) 내 "한국석유공사_주유소 평균가격" API 및 오피넷 사이트 직접 수집.
2. **미국 에너지정보청(EIA) Open Data API v2** — 미국 원유 재고(Weekly Crude Oil Stocks, WCESTUS1), 원유 생산량(Weekly Field Production, WCRFPUS2). 미국 연방정부 공공 데이터.
3. **미국 연방준비은행(FRED) Economic Data API** — 연방기금금리(FEDFUNDS), 미국 달러 인덱스(DTWEXBGS). 미국 연방정부 공공 데이터.

### 민간/해외 공공 데이터
1. **New York Times Article Search API** — 원유(crude oil, petroleum) 관련 영문 뉴스 기사. 무료 티어 500회/일.
2. **The Guardian Open Platform API** — 원유 관련 영문 뉴스 기사. 무료 티어 5,000회/일.

## 사업 계획서 작성 시 강조할 포인트

### 기술적 차별점
1. **하이브리드 예측 엔진**: ML(XGBoost) 정량 분석 + LLM(Gemma 4) 정성 보정의 결합. 순수 시계열 모델의 블랙스완 취약점을 뉴스 기반 보정으로 해결.
2. **유종별 독립 파이프라인**: Dubai/Brent/WTI 각각에 대해 독립적인 뉴스 분류, 영향도 평가, 예측, 브리핑 수행. 유종 간 지정학적 민감도 차이를 반영.
3. **RAG 기반 Market Memory**: ChromaDB 벡터 DB에 과거 뉴스-유가 변동 매핑 데이터를 적재하고, 현재 이슈와 유사한 과거 사례를 검색하여 예측의 설명 가능성(Explainability) 확보.
4. **듀얼 방법론 비교**: Method A (AI Quant) vs Method B (펀더멘탈 수급) 결과를 나란히 비교 표시하여 분석가의 다각도 판단 지원.
5. **로컬 LLM (Ollama)**: 데이터 보안성 — 기업 내부 데이터가 외부 API로 유출되지 않음. Apple Silicon Metal 가속으로 클라우드 대비 비용 절감.

### 사업성 포인트
- 글로벌 에너지 AI 시장: 2026년 약 171.8~278.9억 달러 규모 (Data Bridge / TBRC 전망)
- 에너지 빅데이터 분석 시장: 2026년 약 133.6억 달러, 연평균 12% 성장 (Fortune Business Insights)
- 한국 에너지 수입 의존도 93.5% — 유가 변동 리스크 관리 수요 절대적
- 수익 모델: B2B SaaS 구독 (월정액), API 라이센싱, 맞춤 분석 리포트

### 사회적 가치
- 에너지 가격 투명성 제고: 중소 제조업체에 대기업 수준의 에너지 인텔리전스 접근성 제공
- 공공데이터 활용 확대: 한국석유공사 오피넷 데이터의 AI 결합 활용 모범 사례
- 에너지 안보: 국가 차원의 유가 리스크 조기 경보 시스템으로 활용 가능

### 특허 가능성
1. **하이브리드 유가 추정 방법**: ML 기반 정량 예측과 LLM 기반 뉴스 영향도를 결합하여 유종별 독립 가격 밴드를 산출하는 방법 및 시스템
2. **유종별 독립 뉴스 영향도 평가 방법**: 동일 뉴스 기사에 대해 복수 유종의 민감도를 차별 평가하는 AI 분류 시스템
3. **RAG 기반 에너지 시장 유사 사례 검색 시스템**: 벡터 DB를 활용한 과거 사건-유가 변동 매핑 및 실시간 유사도 검색 방법

### 추가 개방 요청 데이터 (공공데이터 수요)
1. **한국석유공사 국제유가 일별 현물가 Open API** — 현재 오피넷 웹사이트에서만 제공되는 Dubai/Brent/WTI USD 일별 가격을 REST API로 정식 개방 필요.
2. **산업통상자원부 석유수급 통계 API** — 국내 원유 수입량, 정유사별 수입 현황의 실시간 API 개방.
3. **한국에너지공단 에너지 수급 전망 데이터 API** — 연/월별 에너지 수급 전망을 기계 판독 가능한 포맷으로 개방.
4. **환경부 탄소배출권 거래 데이터 API** — ESG/기후 요인이 에너지 가격에 미치는 영향 분석을 위한 일별 탄소배출권 가격 및 거래량 API.

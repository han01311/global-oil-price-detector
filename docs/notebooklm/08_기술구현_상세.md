## 6. 핵심 AI/ML 파이프라인

### 6-1. 뉴스 분류 파이프라인
1. NYT + Guardian에서 원유 관련 기사 수집
2. Gemma 4 (Ollama 로컬)로 6대 요인 분류: geopolitics, supply, demand, macro, climate, speculation
3. 유종별(Dubai/Brent/WTI) 독립 영향도 평가 (Impact Score -5~+5, 방향성, 근거)
4. 분류 결과를 PostgreSQL JSONB 컬럼에 저장
5. ChromaDB에 벡터 임베딩 적재

### 6-2. 가격 예측 파이프라인 (듀얼 방법론)
- **Method A (AI Quant)**: XGBoost 6개 독립 모델 (3유종 × 7일/30일)
  - 피처: 이동평균(5/10/20/50일), 변동률(1/5/10/20일), 변동성(10/20일), 유종 간 스프레드, 거시경제 지표
- **Method B (펀더멘탈)**: 5대 시그널 가중 합산
  - 재고 변화, 생산량 추세, 계절 패턴, 평균 회귀(Ornstein-Uhlenbeck), 달러 역상관
- **News Adjustment**: ChromaDB 유사 사례 검색 → 유종별 News Premium/Discount (%) 산출
- **최종 산출**: Final Price = Baseline × (1 + News Adjustment%), Confidence Band = ± (RMSE + 불확실성)

### 6-3. RAG 기반 Market Memory
- ChromaDB에 뉴스 임베딩 + 당시 유가 변동률을 매핑하여 적재
- 주요 유가 사건 30건 시드 데이터 사전 적재
- 유사 과거 사례 cosine similarity 검색 (유종별 필터)
- 예: "2019 사우디 아람코 피격 +15% → 현재 유사 패턴 감지"

## 8. 인프라 구성
- **데이터베이스**: PostgreSQL 16 (Docker 컨테이너, asyncpg 비동기 드라이버)
- **벡터 DB**: ChromaDB (로컬 임베딩, 서버리스 모드)
- **LLM 서버**: Ollama Native App (Apple Silicon Metal 가속)
- **스케줄러**: APScheduler (AsyncIOScheduler, 기본 6시간 주기)
- **프론트엔드**: Vite Dev Server (port 5173)
- **백엔드**: Uvicorn (port 8000)

## 9. 회복탄력성 (Resilience) 설계
- Rate Limit 중앙 관리 (rate_limiter.py) — API별 일일 한도 + Exponential Backoff
- 외부 API 장애 시 로컬 캐시 Fallback (data/raw/ 디렉토리)
- LLM 서킷 브레이커 — 3회 실패 후 AI 모듈 비활성화 (Graceful Degradation)
- Pydantic 스키마 검증 — 모든 입출력 데이터 Validation
- React ErrorBoundary — 컴포넌트별 부분 장애 격리

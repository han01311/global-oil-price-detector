# Step 5: AI 브리핑 뷰어 구현

## 목표
AI가 생성한 일일 유가 브리핑을 구조화된 형태로 표시하는 뷰어 컴포넌트를 구현한다.

## 작업

### 1. Briefing 컴포넌트
`frontend/src/components/Briefing/BriefingViewer.tsx`:

```
┌─ AI DAILY BRIEFING ─────────────────┐
│ 2024-12-15                           │
│                                      │
│ 📋 핵심 요약                          │
│ WTI $72.50 전망 (현재 $71.20 대비     │
│ +1.8%). OPEC+ 감산 연장 기대감과      │
│ 중국 수요 회복 신호가 주요 요인...      │
│                                      │
│ 📊 주요 요인                          │
│ ┌────────────────────┬──────┐        │
│ │ [SUPPLY] 공급       │ +3   │        │
│ │ OPEC+ 감산 연장     │      │        │
│ ├────────────────────┼──────┤        │
│ │ [DEMAND] 수요       │ +2   │        │
│ │ 중국 PMI 회복       │      │        │
│ └────────────────────┴──────┘        │
│                                      │
│ ⚠ 리스크 시나리오                     │
│ · [HIGH] 이란 제재 완화 시 -$3~5      │
│ · [LOW] 러시아 추가 감산 시 +$2~4     │
│                                      │
│ 📜 과거 유사 사례                     │
│ · 2023-06 OPEC 감산: +4.2% (7일)     │
│ · 2022-11 중국 리오프닝: +8.1% (30일) │
└──────────────────────────────────────┘
```

### 2. 섹션별 구현
- **핵심 요약**: 3줄 텍스트, 가격 수치는 PriceDisplay 활용
- **주요 요인**: 카테고리 뱃지 + 스코어 바
- **리스크 시나리오**: 확률(HIGH/MED/LOW) 뱃지 + 가격 영향
- **과거 유사 사례**: 이벤트명 + 유사도 + 당시 변동률

### 3. 브리핑 히스토리
- "이전 브리핑" 버튼으로 과거 날짜 브리핑 탐색
- 날짜 선택기 (간단한 이전/다음 버튼)

### 4. 데이터 훅
`frontend/src/hooks/useBriefing.ts`

## AC (Acceptance Criteria)
1. AI 브리핑이 구조화된 형태로 렌더링된다
2. 핵심 요약, 주요 요인, 리스크 시나리오, 과거 사례가 모두 표시된다
3. 카테고리 뱃지와 스코어가 올바른 색상으로 표시된다
4. 과거 브리핑 탐색이 가능하다
5. 브리핑 로딩 중 Skeleton이 표시된다
